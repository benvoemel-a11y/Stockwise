# Stockwise

Habit-Tracker als Depot: Was du tust, bewegt deinen Wert in LPI (Life Performance Index).

Die App läuft komplett im Browser und speichert alles nur auf dem eigenen Gerät.

- `index.html`: die komplette App
- `sw.js`: hält die App nach dem ersten Öffnen offline nutzbar
- `manifest.webmanifest`, `icon-180.png`, `icon-512.png`: Name und Symbol für den Home-Bildschirm

Adresse: https://benvoemel-a11y.github.io/Stockwise/
