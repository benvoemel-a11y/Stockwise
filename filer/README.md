# Filer

Minimalistischer Habit-Tracker fürs iPhone – Web-App, läuft offline und speichert nur auf dem Gerät.

**Installieren:** Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.

**Bedienung**
- antippen – erledigt
- nach links wischen – bearbeiten / löschen
- lange drücken – verschieben
- seitlich wischen – anderer Tag
- `!` vor dem Namen – markieren
- Menü › Daten – sichern / laden (auch die `~/.filer.json` vom Mac)
